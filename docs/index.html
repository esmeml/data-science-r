Avant-propos

Ces notes accompagnent les supports de cours et les séances pratiques du module Data Science sous R. Elles ne remplacent pas le cours : elles servent à revoir, approfondir et pratiquer ce qui a été vu en séance. Les chapitres suivent l’organisation des supports de cours.

Objectifs du module

À la fin du module, vous devez être capable de :

  • AAV1 — nommer et reconnaître les types de données et les structures algorithmiques de R ;
  • AAV2 — lire, écrire, transformer et décrire des données de formats variés, et écrire du code R modulaire et lisible ;
  • AAV3 — produire des graphiques avec R (graphiques de base et ggplot2) ;
  • AAV4 — mettre en œuvre une analyse en composantes principales (ACP) et des arbres de décision ;
  • AAV5 — choisir une méthode adaptée à un problème de classification ;
  • AAV6 — évaluer et comparer des méthodes d’analyse factorielle, et décrire une application web R Shiny ;
  • AAV7 — concevoir et évaluer une chaîne de traitement complète pour répondre à un problème d’analyse de données.

Évaluation : contrôle continu 30 %, projet 50 %, examen final 20 %.

Comment utiliser ces notes

  • Les blocs de code sont exécutables : recopiez-les dans RStudio et modifiez-les. On apprend la science des données en pratiquant.
  • Les sorties de R sont précédées de #>.
  • Chaque chapitre se termine par des exercices, avec des solutions repliables dans la version web.
  • Trois types d’encadrés reviennent dans le texte :

À retenir — les idées essentielles à savoir restituer.

Attention — les pièges classiques et les erreurs fréquentes.

Exercice — à faire pendant ou après la séance.

Logiciels et packages

Installez R (version 4.3 ou plus récente) puis RStudio Desktop (voir le chapitre 2). Les packages utilisés dans le module s’installent en une seule commande :

install.packages(c(
  "tidyverse",     # dplyr, tidyr, readr, ggplot2, ...
  "questionr", "readxl", "nycflights13", "ISLR",
  "FactoMineR", "factoextra",
  "rpart", "pROC", "cluster", "shiny"
))

Les données du cours

Le dossier datasets/ contient :

  • phbirths.dat : poids de naissance de 1 115 bébés à Philadelphie ;
  • boutique_clients.csv, boutique_commandes.csv, boutique_categories.csv et boutique_campagne.csv : les données simulées d’une boutique en ligne fictive (2 000 clients, environ 9 500 commandes en 2025, un test A/B d’emailing), fil rouge marketing des chapitres 3 à 6. Elles sont produites par le script generer-boutique.R.

Les autres jeux de données proviennent de packages : hdv2003 et rp2018 (questionr), nycflights13, Carseats, OJ et Caravan (ISLR), decathlon (FactoMineR).
