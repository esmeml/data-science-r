Chapitre 4 Représentations graphiques et régression

Objectifs du chapitre

  • Connaître les principes d’un bon graphique et choisir un graphique adapté aux données.
  • Produire des graphiques avec R de base et, surtout, avec ggplot2 : geoms, mappages, positions, facets, scales, thèmes.
  • Ajuster, interpréter et critiquer une régression linéaire simple et multiple, puis une régression logistique.
library(tidyverse)
library(questionr)   # jeu de données rp2018 (exercices)
library(ISLR)        # jeux de données Carseats et OJ
source("R/boutique.R")
commandes <- lire_boutique("commandes")
clients   <- lire_boutique("clients")

4.1 Pourquoi visualiser ?

La visualisation est un élément essentiel de l’analyse : elle révèle des structures que les résumés numériques cachent. Le quartet d’Anscombe (jeu anscombe) contient quatre séries \((x, y)\) qui ont presque exactement la même moyenne, la même variance, la même corrélation et la même droite de régression :

anscombe_long <- tibble(
  serie = rep(1:4, each = 11),
  x = c(anscombe$x1, anscombe$x2, anscombe$x3, anscombe$x4),
  y = c(anscombe$y1, anscombe$y2, anscombe$y3, anscombe$y4)
)
anscombe_long |>
  group_by(serie) |>
  summarise(moy_x = mean(x), moy_y = mean(y), var_y = var(y), correlation = cor(x, y))
#> # A tibble: 4 × 5
#>   serie moy_x moy_y var_y correlation
#>   <int> <dbl> <dbl> <dbl>       <dbl>
#> 1     1     9  7.50  4.13       0.816
#> 2     2     9  7.50  4.13       0.816
#> 3     3     9  7.5   4.12       0.816
#> 4     4     9  7.50  4.12       0.817

Pourtant, leurs graphiques n’ont rien à voir :

ggplot(anscombe_long, aes(x, y)) +
  geom_point() +
  geom_smooth(method = "lm", se = FALSE, formula = y ~ x) +
  facet_wrap(vars(serie))

Toujours regarder les données avant (et après) de les modéliser. Explorer graphiquement est un processus itératif : on commence simple, puis on affine en regardant les données sous différents angles.

4.1.1 Principes d’un bon graphique

Edward Tufte (The Visual Display of Quantitative Information) propose quelques principes :

  • montrer les données avant tout ;
  • ne pas les déformer (axes tronqués trompeurs, effets 3D) ;
  • encourager l’œil à comparer ;
  • montrer plusieurs niveaux de détail, de la vue d’ensemble à la structure fine.

Un graphique se décompose en quatre éléments : les indices visuels (position, longueur, couleur, taille…), le système de coordonnées (cartésien, polaire, géographique), les échelles (linéaire, logarithmique, catégorielle, temporelle) et le contexte (titre, étiquettes d’axes avec unités, source, lignes de référence).

L’œil compare très bien des positions et des longueurs sur une échelle commune, beaucoup moins bien des angles, des surfaces ou des couleurs. C’est pourquoi un diagramme en barres est presque toujours plus lisible qu’un diagramme circulaire (« camembert »).

4.1.2 Choisir un graphique

Question Variables Graphique ggplot2
Distribution 1 quantitative histogramme, densité, boîte à moustaches geom_histogram(), geom_density()
Répartition 1 qualitative diagramme en barres geom_bar(), geom_col()
Relation 2 quantitatives nuage de points geom_point()
Comparaison quantitative × qualitative boîtes à moustaches, violons geom_boxplot(), geom_violin()
Association 2 qualitatives barres empilées ou juxtaposées geom_bar(position = ...)
Évolution quantitative × temps courbe geom_line()

4.2 Graphiques avec R de base

Les fonctions graphiques de base, vues au chapitre précédent, sont rapides pour explorer :

par(mfrow = c(2, 2))   # grille 2 x 2

hist(Carseats$Sales, breaks = 20, col = "lightblue",
     main = "Ventes par magasin", xlab = "Ventes (milliers d'unités)")
boxplot(Sales ~ ShelveLoc, data = Carseats,
        main = "Ventes selon l'emplacement", xlab = "Emplacement en rayon", ylab = "Ventes")
plot(Sales ~ Price, data = Carseats, pch = 16, cex = 0.6,
     col = ifelse(Carseats$US == "Yes", "red", "grey40"),
     main = "Ventes et prix", xlab = "Prix ($)", ylab = "Ventes")
legend("topright", legend = c("États-Unis", "Hors États-Unis"),
       col = c("red", "grey40"), pch = 16, cex = 0.8)
barplot(table(Carseats$ShelveLoc), main = "Emplacements", col = "tomato")

par(mfrow = c(1, 1))   # rétablir la grille par défaut
Paramètre Rôle Exemple
main, xlab, ylab titres main = "Titre"
col couleur col = "steelblue"
pch symbole des points pch = 16 (disque plein)
cex taille relative cex = 0.5
lty, lwd type et épaisseur de ligne lty = 2 (tirets)
xlim, ylim bornes des axes xlim = c(0, 10)

Les fonctions abline(), lines(), points(), text() et legend() ajoutent des éléments au graphique courant. Pour enregistrer : png("fichier.png"), puis le graphique, puis dev.off(), ou le bouton Export de l’onglet Plots.

4.3 Graphiques avec ggplot2

ggplot2 repose sur une grammaire des graphiques : un graphique est construit en superposant des couches avec l’opérateur +. Une esthétique (aesthetic) est une correspondance explicite entre une variable et un indice visuel.

Composant Rôle Exemple
données un tableau (format tidy) ggplot(Carseats)
mappages (aes()) lien entre variables et attributs graphiques aes(x = Price, y = Sales, color = ShelveLoc)
geoms forme géométrique geom_point(), geom_boxplot()
facets petits multiples facet_wrap(vars(ShelveLoc))
scales réglage des axes, couleurs, tailles scale_y_log10()
thème et titres apparence générale labs(), theme_minimal()

4.3.1 Initialisation et premier geom

Un graphique s’initialise avec ggplot() et un tableau de données. On ajoute ensuite un geom, auquel on indique les variables à représenter via aes(). Les variables s’écrivent sans le nom du tableau (Price et non Carseats$Price).

ggplot(Carseats) +
  geom_point(aes(x = Price, y = Sales))

Les attributs constants se donnent dans le geom, hors de aes() :

ggplot(Carseats) +
  geom_point(aes(x = Price, y = Sales), color = "darkgreen", size = 2, alpha = 0.4)

4.3.2 Les principaux geoms

Histogramme et densité — la distribution des montants de commande :

ggplot(commandes) +
  geom_histogram(aes(x = montant), binwidth = 10, fill = "steelblue", color = "white")

ggplot(commandes) +
  geom_density(aes(x = montant, fill = promo), alpha = 0.4)

L’argument binwidth (ou bins) d’un histogramme et bw d’une densité règlent le niveau de détail : à tester, car ils peuvent masquer ou inventer des structures.

Boîtes à moustaches et violons — le panier selon le canal d’acquisition :

commandes_clients <- left_join(commandes, clients, by = "client_id")

ggplot(commandes_clients) +
  geom_boxplot(aes(x = canal_acquisition, y = montant), fill = "wheat", varwidth = TRUE)

ggplot(commandes_clients) +
  geom_violin(aes(x = canal_acquisition, y = montant), fill = "lightblue")

varwidth = TRUE rend la largeur des boîtes proportionnelle aux effectifs ; le violon montre la forme complète de la distribution.

Barres : geom_bar() et geom_col() — geom_bar() compte les lignes de chaque modalité ; geom_col() représente des valeurs déjà calculées. Passer la variable en y donne des barres horizontales, plus lisibles avec des étiquettes longues (on peut aussi ajouter coord_flip()).

ggplot(commandes) +
  geom_bar(aes(y = categorie))

ca_categorie <- commandes |>
  group_by(categorie) |>
  summarise(ca = sum(montant))

ggplot(ca_categorie) +
  geom_col(aes(x = ca, y = reorder(categorie, ca)), fill = "darkblue") +
  labs(x = "Chiffre d'affaires 2025 (€)", y = NULL)

reorder(categorie, ca) trie les barres selon le chiffre d’affaires : un tri rend la lecture beaucoup plus rapide.

Courbes — l’évolution du chiffre d’affaires mensuel :

ca_mensuel <- commandes |>
  mutate(mois = floor_date(date, "month")) |>
  group_by(mois) |>
  summarise(ca = sum(montant))

ggplot(ca_mensuel, aes(x = mois, y = ca)) +
  geom_line() +
  geom_point()

La saisonnalité est nette : les ventes s’envolent en novembre (Black Friday) et en décembre (Noël).

Texte et étiquettes — geom_text() et geom_label() demandent x, y et label :

ggplot(ca_categorie, aes(x = categorie, y = ca)) +
  geom_col(fill = "grey70") +
  geom_text(aes(label = paste(round(ca / 1000), "k€")), vjust = -0.4)

Nombreux points — quand les points se superposent, geom_bin2d() (ou geom_hex(), qui nécessite le package hexbin) colore une grille selon le nombre de points :

ggplot(commandes) +
  geom_bin2d(aes(x = nb_articles, y = montant), bins = 30)

4.3.3 Mappages

Un mappage relie un attribut graphique (position, couleur, taille, transparence, forme) à une variable. On peut en combiner plusieurs :

ggplot(Carseats) +
  geom_point(aes(x = Price, y = Sales, color = ShelveLoc, size = Advertising), alpha = 0.6)

Ce graphique montre quatre variables : à prix égal, un magasin où le produit est bien placé en rayon (Good) vend nettement plus.

aes() ou pas aes() ? Si l’attribut dépend d’une variable, c’est un mappage : il va dans aes(). S’il est constant, il va hors de aes(). Écrire aes(color = "blue") crée une légende « blue » et une couleur imprévue.

4.3.4 Positions des barres

Avec un mappage fill, l’argument position de geom_bar() contrôle l’agencement des barres :

ggplot(commandes) +
  geom_bar(aes(y = categorie, fill = promo))                     # empilées (défaut)

ggplot(commandes) +
  geom_bar(aes(y = categorie, fill = promo), position = "dodge")  # côte à côte

ggplot(commandes) +
  geom_bar(aes(y = categorie, fill = promo), position = "fill") + # proportions
  labs(x = "Part des commandes")

Les promotions sont surtout utilisées en Mode et en Beauté. Pour comparer des proportions entre groupes de tailles différentes, position = "fill" est le bon choix.

4.3.5 Superposer plusieurs geoms

On ajoute les couches les unes après les autres. Les mappages déclarés dans ggplot() sont hérités par tous les geoms :

ggplot(Carseats, aes(x = ShelveLoc, y = Sales)) +
  geom_boxplot(outlier.shape = NA) +
  geom_jitter(width = 0.2, alpha = 0.3, color = "red")

ggplot(Carseats, aes(x = Price, y = Sales, color = ShelveLoc)) +
  geom_point(alpha = 0.4) +
  geom_smooth(method = "lm", formula = y ~ x, se = FALSE)

Les trois droites sont presque parallèles : l’effet du prix est à peu près le même quel que soit l’emplacement. Nous le vérifierons avec un modèle.

Chaque geom peut aussi avoir ses propres données, par exemple pour étiqueter seulement quelques points :

meilleurs <- Carseats |>
  mutate(magasin = row_number()) |>
  filter(Sales > 14)

ggplot(Carseats, aes(x = Price, y = Sales)) +
  geom_point(alpha = 0.3) +
  geom_label(data = meilleurs, aes(label = magasin), color = "darkred", size = 3)

4.3.6 Faceting

Le faceting répète le même graphique pour chaque modalité d’une variable qualitative, avec les mêmes échelles, ce qui permet la comparaison directe.

commandes |>
  mutate(mois = floor_date(date, "month")) |>
  group_by(categorie, mois) |>
  summarise(ca = sum(montant), .groups = "drop") |>
  ggplot(aes(x = mois, y = ca)) +
  geom_line() +
  facet_wrap(vars(categorie))

facet_grid(rows = vars(a), cols = vars(b)) dispose les graphiques selon une grille croisant deux variables.

4.3.7 Scales

Les scales contrôlent la façon dont les valeurs sont traduites en attributs graphiques, et la légende ou l’axe correspondant. Elles prennent la forme scale_<attribut>_<type>().

Axes — titres, limites, format des nombres, échelle logarithmique :

ggplot(ca_mensuel, aes(x = mois, y = ca)) +
  geom_line() +
  scale_x_date("Mois", date_labels = "%m/%Y", date_breaks = "2 months") +
  scale_y_continuous("Chiffre d'affaires", limits = c(0, NA),
                     labels = scales::label_number(suffix = " €", big.mark = " "))

Faire partir l’axe des ordonnées de 0 évite d’exagérer visuellement les variations, ce qui est essentiel pour des barres. Les montants, très asymétriques, se lisent mieux en échelle logarithmique :

ggplot(commandes_clients) +
  geom_boxplot(aes(x = canal_acquisition, y = montant)) +
  scale_y_log10("Montant (€, échelle log)")

Couleurs — pour une variable quantitative, scale_color_gradient(), scale_color_viridis_c() ou scale_color_distiller() ; pour une variable qualitative, scale_color_brewer(), scale_color_viridis_d() ou scale_color_manual() :

ggplot(Carseats) +
  geom_point(aes(x = Price, y = Sales, color = Advertising)) +
  scale_color_viridis_c("Budget pub (k$)")

ggplot(Carseats) +
  geom_point(aes(x = Price, y = Sales, color = ShelveLoc)) +
  scale_color_manual("Emplacement",
                     values = c(Bad = "firebrick", Medium = "grey60", Good = "forestgreen"))

Les palettes viridis et certaines palettes ColorBrewer restent lisibles pour les personnes daltoniennes (RColorBrewer::display.brewer.all() les liste).

Tailles — scale_size(range = c(min, max)).

4.3.8 Titres et thèmes

labs() définit le titre, le sous-titre, la source et les noms des axes et légendes ; les thèmes (theme_minimal(), theme_bw(), theme_classic()…) règlent l’apparence générale, et theme() permet de modifier chaque élément.

ggplot(ca_mensuel, aes(x = mois, y = ca / 1000)) +
  geom_col(fill = "steelblue") +
  labs(title = "Novembre et décembre réalisent plus d'un quart des ventes annuelles",
       subtitle = "Chiffre d'affaires mensuel de la boutique en ligne, 2025",
       x = NULL, y = "Chiffre d'affaires (k€)",
       caption = "Source : données simulées du cours") +
  theme_minimal()

Un graphique de présentation : un titre qui énonce le message, des axes avec unités, une source, des couleurs lisibles, aucun effet inutile. Enregistrer avec ggsave("figure.png", width = 8, height = 5, dpi = 300).

Le package esquisse (menu Addins de RStudio, ou esquisse::esquisser()) permet de construire un graphique ggplot2 à la souris, puis de récupérer le code correspondant : pratique pour explorer ou retrouver une syntaxe.

4.4 Régression linéaire simple

4.4.1 Le modèle

On cherche à expliquer une variable quantitative \(Y\) (la réponse) par une variable quantitative \(X\) (le prédicteur) :

\[Y_i = \beta_0 + \beta_1 X_i + \varepsilon_i, \qquad i = 1, \dots, n\]

  • \(\beta_0\) : ordonnée à l’origine ;
  • \(\beta_1\) : pente, c’est-à-dire la variation moyenne de \(Y\) quand \(X\) augmente d’une unité ;
  • \(\varepsilon_i\) : erreur, supposée centrée, de variance constante \(\sigma^2\), indépendante d’une observation à l’autre (et gaussienne pour les tests).

La méthode des moindres carrés ordinaires choisit \(\hat\beta_0\) et \(\hat\beta_1\) qui minimisent la somme des carrés des résidus \(\sum_i (Y_i - \hat\beta_0 - \hat\beta_1 X_i)^2\). On obtient :

\[\hat\beta_1 = \frac{\operatorname{cov}(X, Y)}{\operatorname{var}(X)}, \qquad \hat\beta_0 = \bar Y - \hat\beta_1 \bar X\]

4.5.4 Évaluer la prédictibilité (cadre PCS)

On mesure la qualité prédictive sur des données non utilisées pour l’ajustement, et on la compare à une référence naïve (prédire la moyenne).

set.seed(2026)
indices_train <- sample(nrow(Carseats), size = round(0.7 * nrow(Carseats)))
train <- Carseats[indices_train, ]
test  <- Carseats[-indices_train, ]

rmse <- function(observe, predit) sqrt(mean((observe - predit)^2))

m1 <- lm(Sales ~ Price, data = train)
m2 <- lm(Sales ~ Price + CompPrice + Advertising + ShelveLoc + Age + Income, data = train)
c(reference = rmse(test$Sales, mean(train$Sales)),
  simple    = rmse(test$Sales, predict(m1, test)),
  multiple  = rmse(test$Sales, predict(m2, test)))
#> reference    simple  multiple 
#>     2.971     2.638     1.059

La racine de l’erreur quadratique moyenne (RMSE) est en milliers d’unités. Le modèle multiple divise l’erreur par plus de deux. Changez la graine : le classement des modèles reste-t-il le même ? C’est une vérification de stabilité.

4.6 Régression logistique

4.6.1 Quand la réponse est binaire

Pour prédire une variable binaire (achète / n’achète pas, résilie / reste), la régression linéaire ne convient pas : elle peut prédire des valeurs hors de \([0, 1]\). La régression logistique modélise la probabilité \(p = P(Y = 1 \mid X)\) via la fonction logit :

\[\log \frac{p}{1 - p} = \beta_0 + \beta_1 X_1 + \dots + \beta_p X_p \quad \Longleftrightarrow \quad p = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X_1 + \dots)}}\]

Le rapport \(p / (1 - p)\) est la cote (odds). Les coefficients sont estimés par maximum de vraisemblance avec glm(..., family = binomial).

4.6.2 Exemple : choix de marque

Le jeu OJ (package ISLR) décrit 1 070 achats réels de jus d’orange dans cinq magasins américains, issus de données de caisse utilisées dans l’ouvrage Business Analysis Using Regression (Foster, Stine et Waterman, 1998). À chaque achat, le client a choisi entre deux marques, Citrus Hill (CH) et Minute Maid (MM). Qu’est-ce qui fait choisir Minute Maid ? Ces données sont réutilisées au chapitre 5.

StoreID, STORE, Store7 magasin de l’achat (identifiant ; codage alternatif ; magasin n° 7 ou non)

SalePriceCH, SalePriceMM prix de vente, après remise ($)

4.7 Résumé

  • Visualiser avant de modéliser (quartet d’Anscombe) ; un graphique a un message, des axes avec unités, une source.
  • R de base : plot(), hist(), boxplot(), barplot() ; paramètres col, pch, cex, main, xlab… ; par(mfrow = ...).
  • ggplot2 : ggplot(données) + geom_*(aes(...)) ; mappages dans aes(), constantes hors de aes() ; position des barres ; facet_wrap(vars()) ; scale_*() ; labs(), theme_*() ; ggsave().
  • Régression linéaire : lm(y ~ x1 + x2, data), summary(), coef(), confint(), predict(), diagnostics avec plot(modele).
  • Interpréter chaque coefficient « toutes choses égales par ailleurs » ; oublier une variable importante biaise les autres ; association \(\neq\) causalité.
  • Comparer les modèles sur des données de validation (RMSE), face à une référence naïve.
  • Régression logistique : glm(y ~ ..., family = binomial) ; exp(coef()) donne les rapports de cotes ; predict(type = "response") les probabilités.

Exercice 4.4 — Poids de naissance. Avec phbirths (datasets/phbirths.dat), modéliser le poids de naissance (grams) en fonction de la durée de gestation, puis ajouter le tabagisme de la mère (smoke). Interpréter le coefficient de smoke, puis ajuster une régression logistique du faible poids (moins de 2 500 g).

Solution 
phbirths <- read.table("../datasets/phbirths.dat")
coef(lm(grams ~ gestate + smoke, data = phbirths))
#> (Intercept)     gestate   smokeTRUE 
#>     -3027.0       162.0      -190.6
glm(I(grams < 2500) ~ gestate + smoke, data = phbirths, family = binomial) |>
  coef() |> exp() |> round(3)
#> (Intercept)     gestate   smokeTRUE 
#>   1.061e+12   4.490e-01   2.349e+00

À durée de gestation égale, les bébés de mères fumeuses pèsent environ 190 g de moins en moyenne.
